静态博客搭建笔记

用 Python + Markdown 从零搭建个人博客，部署到 GitHub Pages

项目结构

my-blog/
├── content/              # 内容目录
│   ├── posts/            # 文章（.md 文件）
│   └── works/            # 作品集（.md 文件）
├── templates/            # HTML 模板
│   ├── base.html         # 公共骨架（导航、页脚）
│   ├── index.html        # 首页
│   ├── post.html         # 文章详情页
│   ├── work.html         # 作品详情页
│   ├── works.html        # 作品集列表页
│   └── search.html       # 搜索页
├── static/
│   └── style.css         # 样式（现代卡片 + 米白蓝渐变）
├── output/               # 构建产物（自动生成，不要手动修改）
├── .github/
│   └── workflows/
│       └── deploy.yml    # GitHub Actions 自动部署
├── build.py              # 构建脚本
├── serve.py              # 本地预览服务器
└── README.md

环境准备

# 确认 Python 版本（需要 3.8+）
python --version

# 安装依赖
pip install markdown jinja2

写文章

在 content/posts/ 下新建 .md 文件：

title: 文章标题
date: 2024-01-01
tags: 技术, 随笔
project: 静态博客生成器

## 正文从这里开始

支持标准 Markdown 语法。

头部字段说明：

字段 是否必填 说明
title 否 不填则用文件名代替
date 否 不填则用今天日期
tags 否 不填则不显示标签

写作品

在 content/works/ 下新建 .md 文件：

title: 作品名称
desc: 一句话描述
link: https://github.com/你的用户名/项目名

## 详细介绍

本地预览

python serve.py
# 打开浏览器访问 http://localhost:8000
# 修改文件后自动重新构建，刷新浏览器即可看到效果

构建

python build.py

构建完成后，output/ 目录就是完整的静态网站。

发布新文章（日常流程）

# 1. 在 content/posts/ 新建 .md 文件，写好内容

# 2. 本地构建验证
python build.py

# 3. 推送到 GitHub，自动触发部署
git add .
git commit -m "new post: 文章标题"
git push

等 GitHub Actions 变绿（约 1~2 分钟），博客自动更新。

部署配置

GitHub Actions 自动部署

每次推送到 main 分支，自动构建并发布到 GitHub Pages。

配置文件：.github/workflows/deploy.yml

GitHub Pages 设置

  • 仓库 → Settings → Pages
  • Source 选 Deploy from a branch
  • Branch 选 gh-pages，目录选 / (root)

Git 推送（SSH 方式）

服务器网络限制了 443 端口，需要用 SSH 推送：

# 第一次配置（已完成，记录备用）
ssh-keygen -t ed25519 -C "damoxu" -f ~/.ssh/id_ed25519_damoxu
# 公钥已添加到 GitHub damoxu 账号

# SSH config（~/.ssh/config）
# Host github-damoxu
#   HostName github.com
#   User git
#   IdentityFile ~/.ssh/id_ed25519_damoxu

# 远程地址
# git remote set-url origin git@github-damoxu:damoxu/damo-.git

# 每次登录服务器后，如果设置了 passphrase，需要先运行：
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519_damoxu

build.py 核心逻辑

读取 Markdown 文件
    ↓
提取头部元数据（title / date / tags）
    ↓
正文转成 HTML
    ↓
填入 Jinja2 模板
    ↓
写到 output/ 目录

构建顺序：

  1. 清空 output/ 目录
  2. 复制 static/ 静态文件
  3. 生成每篇文章页面
  4. 生成每个作品页面
  5. 生成作品集列表页
  6. 生成首页
  7. 生成搜索索引（search-index.json）
  8. 生成搜索页

常见问题

文章显示"无标题"

检查 Markdown 文件头部格式，title: 后面要有空格：

title: 这是标题       ← 正确
title:这是标题        ← 错误，缺少空格

推送超时

服务器 443 端口被封，使用 SSH 方式推送（见上方 Git 推送章节）。

页面样式没更新

GitHub Pages 有缓存，用无痕窗口或强制刷新： - Chrome：Ctrl + Shift + R - 或右键刷新按钮 → 清空缓存并硬性重新加载

作品集页面 404

确认 build.py 里有生成 works/index.html 的步骤， 且 templates/works.html 文件存在。
