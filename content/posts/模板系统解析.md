# 模板系统解析：Jinja2 模板

> 模板决定了每个页面长什么样，数据由 build.py 填入。

---

## 模板继承关系

```
base.html          ← 公共骨架（导航、页脚、head）
    ├── index.html      首页
    ├── post.html       文章详情页
    ├── work.html       作品详情页
    ├── works.html      作品集列表页
    └── search.html     搜索页
```

所有页面都继承自 `base.html`，只需要填写各自的内容区域。

---

## base.html

公共骨架，每个页面都有的部分：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <title>{{ page_title }} - {{ blog_title }}</title>
  <link rel="stylesheet" href="{{ base_url }}/static/style.css">
</head>
<body>
  <header>导航栏</header>

  <main>
    {% block content %}{% endblock %}  ← 子模板填这里
  </main>

  <footer>页脚</footer>
</body>
</html>
```

---

## 子模板写法

```html
{% extends "base.html" %}        ← 继承父模板

{% set page_title = post.title %} ← 设置页面标题

{% block content %}               ← 填充内容区域
  <article>
    <h1>{{ post.title }}</h1>
    {{ post.body | safe }}        ← safe 表示不转义 HTML
  </article>
{% endblock %}
```

---

## 常用模板语法

```html
<!-- 输出变量 -->
{{ post.title }}

<!-- 不转义 HTML -->
{{ post.body | safe }}

<!-- 循环 -->
{% for post in posts %}
  <li>{{ post.title }}</li>
{% endfor %}

<!-- 条件判断 -->
{% if work.link != "#" %}
  <a href="{{ work.link }}">查看项目</a>
{% endif %}

<!-- 设置变量 -->
{% set page_title = "首页" %}
```

---

## 每个模板接收的数据

| 模板 | 接收的变量 |
|------|-----------|
| index.html | posts（列表）、works（列表） |
| post.html | post（单篇文章） |
| work.html | work（单个作品） |
| works.html | works（列表） |
| search.html | posts、works |

以上变量都由 `build.py` 的 `render_page()` 传入。
